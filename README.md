# Mengting Wang CV site draft

This is a local, static, bilingual CV page inspired by the structure of the supplied Academic Pages example. Open `index.html` for Chinese and `en/index.html` for English. The stylesheet is in `assets/cv.css`. The print button lets a browser print or save a page as PDF. The `files/` directory contains the Chinese and English PDF CVs copied from the supplied source folder.

## Before publishing

- The Chinese CV named by the user as the current source is authoritative for the paper count and status of “Mn-Regulated Quaternary Molten Alloys for CO2-Free Hydrogen Production via Methane Pyrolysis”; it is included as a published paper here.
- Contact phone, birth date, political affiliation, and physical address are omitted from the public-facing draft.
- Two project entries and the Fuel reviewer service were added based on the user’s confirmation and the supplied reference CV. Pending, unpublished patent applications were left off; granted patents and applications with publication numbers are included.
- The attached PDFs are copies of the supplied CV PDFs. The two added project entries and the Fuel reviewer role are reflected on the webpages; they have not been added to the source PDFs.
- The source PDFs retain their original phone number, birth date, political affiliation, and address fields even though those fields are omitted from the webpages.
- Please confirm titles, author order, journal issue metadata, patent inventorship, project role/funding, and current statuses before using the page as an official CV.

The page has no build dependencies. To host it on GitHub Pages, copy these files into a repository configured for Pages and publish the repository; this local draft has not been deployed.
